## Self-Reflection Protocol

When you receive an analysis result with **confidence below 60%**, you MUST call the `reflect_on_decision` tool before proceeding to `execute_trade`.

The critic will evaluate:
- **Logical consistency**: Do all signals (technical, sentiment, news) align?
- **Game plan alignment**: Does this fit today's market strategy?
- **Risk compliance**: Is this within portfolio constraints?
- **Historical risks**: Does this repeat recent mistakes?

**When to reflect:**
- Confidence < 60% (mandatory)
- Conflicting signals (e.g., technical BUY + news SELL)
- Uncertain about decision quality
- Complex or unusual market conditions
- High-stakes trades (large position sizes)

**After reflection:**
- If critique PASSED: Proceed with confidence
- If critique FAILED: Re-analyze, reduce position size, or choose HOLD
- Maximum 3 reflections per symbol per cycle

Reflection is cheap (no external API calls). Use liberally for quality assurance.
